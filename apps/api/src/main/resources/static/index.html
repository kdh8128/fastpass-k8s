Scenario

선착순 처리 흐름

  1. 신청 요청을 API가 수신합니다.
  2. 신청 상태를 PENDING으로 저장합니다.
  3. applicationId를 Redis Queue에 적재합니다.
  4. Worker가 Queue를 소비하며 SUCCESS/FAILED를 결정합니다.
